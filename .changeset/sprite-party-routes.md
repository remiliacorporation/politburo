Configure fallback routes in `tiers.models.sprite.routes` instead of `tiers.models.sprite.model`. Export `PI_FALLBACK_TIERS` using `swarm sprite routes` before launching with the router installed. The sprite launcher defaults to Cursor Grok; select `fallback/codex-cursor` to use the router. The extra Codex account alias and its credential seeding are no longer supported.
