The inspector shows every repo on one board: a repo per channel prefix, a sidebar entry per repo with its counts, a repo on each Work row, `/r/<tag>` and `?repo=` to show one, and Health per repo. The composer can start a task for a person: it is claimed as it is created, then held, so no agent sees it as ready. A plain hold waits. A request that still needs an answer is under Needs you. A work id names a repo only when that tag is already one on the board.
