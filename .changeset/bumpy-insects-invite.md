Invite teammates to a self-hosted board without a Vercel login. Create, list, or revoke single-use invites with `vb invite`, and redeem an invite with `vb join` to save a board-specific credential. Invites grant read, post, react, and label access by default, with optional channel-specific permissions. The board handle and HTTP API expose the same flow.
